PROBLEM STATEMENT
ò Large Language Models generate text based on statistical token prediction rather than explicit factual 
verification. 
ò This leads to hallucinations, where incorrect or fabricated information is presented with high confidence. 
ò Current approaches (RAG, GraphRAG, CoVe, Self-RAG, CRAG) mainly retrieve information before generation or 
verify answers after generation. 
ò They lack claim-level evidence sufficiency assessment, localized reasoning repair, and adaptive inference
during response generation. 
ò There is a need for a self-healing inference architecture that minimizes hallucinations while preserving 
factual accuracy, computational efficiency, and user trust.

Existing Method Core Idea Strength Limitation
Traditional LLM Generates text using next-token prediction Fast and fluent response generation No factual verification or evidence checking
RAG Retrieves external documents before answering Improves factual grounding Retrieval happens mostly before generation; weak claim-level checking.

CORE CONTRIBUTIONS
1. Claim Risk Estimator (CRE)
ò Predicts the hallucination risk of each atomic claim before 
reasoning begins. 
ò Identifies high-risk claims that require additional verification. 
ò Enables adaptive inference by avoiding unnecessary processing 
for low-risk claims. 
2. Adaptive Evidence Sufficiency Predictor (AESP)
ò Determines whether the available evidence is sufficient to 
support each claim. 
ò Dynamically decides when additional retrieval is required. 
ò Reduces unnecessary retrieval while maintaining factual 
reliability. 
3. Dynamic ClaimûEvidence Graph (DCEG)
ò Constructs a structured graph linking each claim with supporting 
evidence. 
ò Maintains confidence scores, dependencies, contradictions, and 
evidence freshness. 
ò Provides transparent and explainable reasoning. 
.
4. Localized Self-Healing Engine (LSHE)
ò Detects unsupported or conflicting claims during 
inference. 
ò Repairs only the affected reasoning segments instead of 
regenerating the entire response. 
ò Improves efficiency while preserving verified content. 
5. Adaptive Claim-Aware Generation (ACAG)
ò Generates responses using claim reliability, evidence 
quality, contradiction analysis, and reasoning consistency. 
ò Produces responses with calibrated confidence instead of 
relying solely on language-model probabilities

CONCLUSION
Conclusion
VeriGen proposes an adaptive inference architecture integrating 
semantic query understanding, claim-level reasoning, evidence 
sufficiency estimation, adaptive retrieval, dynamic evidence graphs, 
localized self-healing, and reliability-aware generationùimproving 
factual consistency while reducing hallucinations and unnecessary 
retrieval.
